1. AI-Powered Speech-to-Text Profanity Classification
   Status: PLANNED
   Effort: HIGH
   Impact: HIGH
   
   What it does:
   ✗ Replace current regex-based profanity detection with ML toxicity classifier
   ✗ Use TensorFlow.js @tensorflow-models/toxicity for in-browser detection
   ✗ OR integrate Claude Haiku API for advanced classification (~$0.001/call)
   ✗ Catches contextual toxicity that keyword lists miss
   ✗ Handles slang, accents, and word variations automatically
   
   Pros:
   - More accurate than keyword matching
   - Handles contextual profanity better
   - Reduces false positives and false negatives
   
   Cons:
   - Increased latency risk
   - API dependency if not using TensorFlow.js locally
   - Increased debugging complexity
   - Additional training/tuning may be needed
   
   Recommended Approach:
   - Start with TensorFlow.js local model (no API dependency)
   - Keep latency under 600ms target
   - Fallback to regex if model load fails
   
   Implementation File: client/src/audio/AIToxicityDetector.js (NEW)


2. AI-Based Disruptive Behavior Detection
   Status: PLANNED
   Effort: MEDIUM
   Impact: HIGH
   
   What it does:
   ✗ Analyze user behavior patterns (not speech content)
   ✗ Detect interruptions, excessive talking, volume spikes
   ✗ Identify long continuous monologues
   ✗ Issue warnings for disruptive behavior independently
   ✗ Support moderation even without profanity detection
   
   Inputs for AI Analysis:
   - Speaking frequency (percentage of room speaking time)
   - Number of interruptions (overlaps with other speakers)
   - Volume consistency (spikes above threshold)
   - Monologue duration (speaking time >30 seconds continuously)
   
   Pros:
   - Privacy-preserving (only metadata, no speech content)
   - Highly unique feature
   - Supports vote-kick and moderation systems
   - Academically defensible
   
   Cons:
   - Requires behavior data collection over time
   - Slightly abstract to explain to users
   - Fine-tuning thresholds needed per room type
   
   Implementation Files:
   - client/src/audio/BehaviorAnalyzer.js (NEW)
   - server/src/utils/behaviorModeration.js (NEW)
