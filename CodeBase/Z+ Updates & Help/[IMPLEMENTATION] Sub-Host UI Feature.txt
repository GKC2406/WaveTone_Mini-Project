================================================================================
USER EXPERIENCE FLOW
================================================================================

SCENARIO 1: Room Creator (becomes Host)
1. Create room → automatically becomes "Host"
2. See "Make Sub-Host" button under each participant
3. Click button → Participant becomes Sub-Host ⭐
4. Can click again to revoke Sub-Host status

SCENARIO 2: Host Leaves Room
1. Host disconnects → 5-minute timeout starts
2. Highest-ranked Sub-Host promoted to Host automatically
3. All users see toast: "[Name] promoted to Host!"
4. New Host gains Host permissions
5. Host can return within 5 minutes to reclaim position

SCENARIO 3: Multiple Sub-Hosts
1. Host assigns multiple Sub-Hosts with ranking
2. If Host leaves → Highest-ranked becomes Host
3. If new Host leaves → Next ranked becomes Host
4. Ensures session continuity with backup leaders

SCENARIO 4: Regular User (Non-Host)
1. Can't see Sub-Host management options
2. Can see Sub-Host badges on participants
3. Can see who is Host
4. Participate normally in voting/kick system
